# Химия — учебный сайт СПбГМТУ

Статический сайт кластера учебных сайтов СПбГМТУ по курсу общей и
неорганической химии (кафедра 2820, 1–2 семестры, 252 ч, экзамен в каждом
семестре). Три части:

* **курс теории** — девять глав по лекционной программе: строение атома,
  химическая связь, термодинамика, кинетика и равновесие, растворы и pH,
  реакции ОВР, электрохимия, коррозия металлов, материалы и вода;
* **разобранные задачи** — двадцать три расчёта в едином формате
  «формула — подстановка — результат» плюс три живых калькулятора;
* **лабораторный практикум** — семь работ на виртуальном стенде.

Прод: <https://shadeswd.duckdns.org/chem/>

## Практикум

Опыт на стенде выполняется по шагам: пока действие текущего шага не сделано,
следующий закрыт, а неверное действие даёт объясняющее сообщение, а не
молчание. Наблюдаемый результат не назначен сценарием — он **считается**:

* pH раствора, цвет индикатора по его интервалу перехода, гидролиз солей;
* выпадение осадка — сравнением произведения концентраций ионов с ПР;
* объём газа — по стехиометрии и молярному объёму;
* масса на электроде и объём газа при электролизе — по закону Фарадея;
* ЭДС — по уравнению Нернста;
* жёсткость воды — по объёму титранта;
* время реакции — по закону действующих масс и правилу Вант-Гоффа.

Все формулы — те же, что в главах теории, поэтому практикум и теория не
расходятся. Ядро (`chemcore.js`) не обращается к DOM и прогоняется в node из
`tests/test_chemcore.py`; часть контрольных значений взята прямо из
разобранных задач практических занятий кафедры.

Журнал работы хранится в `localStorage`: студент вносит показания и расчёты,
стенд сверяет их с истинными значениями и показывает относительную
погрешность. Значение с погрешностью больше допустимой не засчитывается.

Работа добавляется двумя файлами — `site/assets/lab-<имя>.js` с определением
и `site/l-<имя>.html` со страницей; контракт описан в шапке `assets/lab.js`,
а удерживается тестами `tests/test_lab.py`.

## Безопасность

Практикум описывает работы, которые выполняются **на занятии в лаборатории
под руководством преподавателя**. На каждой странице стоит блок о том, что
работа не воспроизводится дома, и отдельный раздел техники безопасности с
правилами именно этой работы. Никаких методик, опасных для самостоятельного
повторения, на сайте нет.

## Развёртывание

```bash
cd deploy && docker compose up -d      # nginx:alpine на 127.0.0.1:8090
```

В compose обязателен ключ `name:` — без него имя проекта берётся из каталога
`deploy` и конфликтует с соседними компоузами.

nginx на домене проксирует `/chem/` на порт 8090 и подставляет общие виджеты
кластера (`hub.js`, `gloss.js`, `mathfmt.js`) перед `</body>`.
