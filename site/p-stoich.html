Задачи 1–5. Расчёты по уравнениям реакций

Основа всех количественных расчётов — переход «масса → моли → моли по коэффициентам → масса или объём». Уравнение реакции связывает не граммы, а количества вещества: коэффициенты — это отношения чисел молей. Отдельно разобран закон эквивалентов, который позволяет обойтись без уравнения вообще, и типичная ловушка, когда один из реагентов взят в недостатке.

Коротко

  • Количество вещества: n = m/M для любого вещества и n = V/Vм для газа при нормальных условиях, Vм = 22,4 л/моль.
  • Коэффициенты уравнения — это отношение чисел молей, а не масс.
  • Если даны количества двух реагентов, расчёт всегда ведут по недостатку: сначала проверяют, какой из них закончится первым.
  • Эквивалент — масса, реагирующая с одним молем атомов водорода; Э = A/B, где B — валентность. Вещества реагируют равным числом эквивалентов.
  • Если реагент задан раствором, в реакцию вступает только растворённое вещество, а не весь раствор.
Ключевые формулы. $$ n=\frac{m}{M},\qquad n=\frac{V}{V_\text{м}},\qquad \frac{m_1}{\text{Э}_1}=\frac{m_2}{\text{Э}_2},\qquad C=\frac{m}{MV}. $$

Задача 1. Масса щёлочи для полной нейтрализации кислоты

Дано: m(H2SO4) = 9,8 г. Найти: m(NaOH) для полной нейтрализации.

Полная нейтрализация означает, что замещаются оба атома водорода кислоты и образуется средняя соль:

H2SO4 + 2NaOH = Na2SO4 + 2H2O

Если щёлочи взять вдвое меньше, получится кислая соль NaHSO4 — поэтому слово «полной» в условии существенно.

Молярные массы (атомные массы округляем до целых, кроме хлора):
M(H2SO4) = 2·1 + 32 + 4·16 = 98 г/моль, M(NaOH) = 23 + 16 + 1 = 40 г/моль.
Количество вещества кислоты:
n(H2SO4) = m/M = 9,8 / 98 = 0,1 моль
г / (г/моль) = моль
По уравнению на 1 моль кислоты приходится 2 моль щёлочи:
n(NaOH) = 2n(H2SO4) = 2 · 0,1 = 0,2 моль
Обратный переход к массе:
m(NaOH) = n·M = 0,2 · 40 = 8 г
моль · (г/моль) = г
Ответ: 8 г NaOH.

Задача 2. Объём водорода при растворении алюминия

Дано: m(Al) = 10,8 г, избыток соляной кислоты, нормальные условия. Найти: V(H2).
2Al + 6HCl = 2AlCl3 + 3H2↑

Кислота взята в избытке, поэтому расчёт ведётся по алюминию.

Количество вещества алюминия:
n(Al) = m/M = 10,8 / 27 = 0,4 моль
Из коэффициентов: 2 моль Al дают 3 моль H2, то есть на моль алюминия — полтора моля водорода:
n(H2) = 1,5·n(Al) = 1,5 · 0,4 = 0,6 моль
Объём газа через молярный объём:
V(H2) = n·Vм = 0,6 · 22,4 = 13,44 л
моль · (л/моль) = л
Молярный объём 22,4 л/моль справедлив только при нормальных условиях (0 °C, 101,3 кПа) и только для газа. Если в условии стандартные условия (25 °C), объём моля уже 24,5 л; если давление другое — считать надо через уравнение состояния, а не по 22,4.
Ответ: 13,44 л водорода.

Задача 3. Масса осадка, когда один реагент в недостатке

Дано: m(Pb(NO3)2) = 3,31 г, m(NaI) = 1,50 г. Найти: m(PbI2).
Pb(NO3)2 + 2NaI = PbI2↓ + 2NaNO3

Даны количества обоих реагентов — значит, нельзя просто взять любой из них. Сначала выясняем, какой закончится раньше.

Молярные массы:
M(Pb(NO3)2) = 207 + 2·(14 + 3·16) = 331 г/моль, M(NaI) = 23 + 127 = 150 г/моль, M(PbI2) = 207 + 2·127 = 461 г/моль.
Количества вещества:
n(Pb(NO3)2) = 3,31 / 331 = 0,01 моль, n(NaI) = 1,50 / 150 = 0,01 моль.
Проверка на недостаток: на 0,01 моль соли свинца по уравнению требуется вдвое больше иодида:
nтреб(NaI) = 2 · 0,01 = 0,02 моль, а есть только 0,01 моль — иодид натрия в недостатке, расчёт ведём по нему.
Из коэффициентов 2 моль NaI дают 1 моль осадка:
n(PbI2) = n(NaI)/2 = 0,01 / 2 = 0,005 моль
Масса осадка:
m(PbI2) = 0,005 · 461 = 2,31 г
Если бы расчёт велся по нитрату свинца, ответ вышел бы вдвое больше — 4,61 г. Это самая частая ошибка в задачах, где даны оба реагента: проверка на недостаток обязательна всегда, даже когда числа выглядят «подогнанными».
Ответ: 2,31 г PbI2; половина нитрата свинца остаётся в растворе непрореагировавшей.

Задача 4. Закон эквивалентов: где выделится больше водорода

Дано: три одинаковые по массе навески — цинк, алюминий и кремний — растворены в избытке щёлочи. Найти: у какого металла объём выделившегося водорода больше; посчитать для навески 1 г.

Решать «в лоб» — составлять три уравнения, подбирать коэффициенты и трижды считать — не нужно. Закон эквивалентов даёт ответ сразу: вещества реагируют равным числом эквивалентов, поэтому чем больше эквивалентов металла в навеске, тем больше эквивалентов водорода выделится.

Эквивалент элемента Э = A/B (A — атомная масса, B — валентность):
Э(Zn) = 65 / 2 = 32,5 г/моль, Э(Al) = 27 / 3 = 9 г/моль, Э(Si) = 28 / 4 = 7 г/моль.
Число эквивалентов в навеске массой m равно m/Э; сравнение при одинаковой m сводится к сравнению эквивалентов:
m/7 > m/9 > m/32,5, то есть кремний > алюминий > цинк.
Эквивалентный объём водорода: молярный объём 22,4 л приходится на 2 г H2, а эквивалент водорода — 1 г, поэтому
Vэ(H2) = 22,4 / 2 = 11,2 л/моль-экв
Объём водорода на 1 г каждой навески, V = m·Vэ/Э:
Si: 1 · 11,2 / 7 = 1,60 л; Al: 1 · 11,2 / 9 = 1,24 л; Zn: 1 · 11,2 / 32,5 = 0,345 л.
Проверка обычным способом — по уравнениям реакций:
Si + 2NaOH + H2O = Na2SiO3 + 2H2↑
n(Si) = 1 / 28 = 0,0357 моль, n(H2) = 2 · 0,0357 = 0,0714 моль, V = 0,0714 · 22,4 = 1,60 л — совпадает.
Ответ: больше всего водорода даёт кремний — 1,60 л на грамм навески против 1,24 л у алюминия и 0,345 л у цинка.

Задача 5. Объём раствора кислоты для реакции с металлом

Дано: m(Mg) = 4,8 г, раствор HCl с молярной концентрацией C = 2 моль/л. Найти: V раствора кислоты.
Mg + 2HCl = MgCl2 + H2↑

Ключевая мысль: в реакцию вступает не раствор, а растворённое в нём вещество. Молярная концентрация как раз и переводит объём раствора в количество вещества.

Количество вещества магния:
n(Mg) = 4,8 / 24 = 0,2 моль
По уравнению на 1 моль магния нужно 2 моль кислоты:
n(HCl) = 2 · 0,2 = 0,4 моль
Объём раствора из определения молярной концентрации C = n/V:
V = n/C = 0,4 / 2 = 0,2 л = 200 мл
моль / (моль/л) = л
Ответ: 200 мл раствора соляной кислоты.

Что проверить в своём решении

Почему нельзя приравнивать массы по коэффициентам уравнения?

Коэффициент показывает, сколько молекул (то есть молей) вещества участвует в реакции, а масса моля у разных веществ разная. В уравнении 2H2 + O2 = 2H2O коэффициенты 2 : 1 : 2, а массы относятся как 4 : 32 : 36. Закон сохранения массы выполняется для сумм (4 + 32 = 36), но не для отдельных коэффициентов.

Когда закон эквивалентов действительно экономит время?

Когда нужно сравнить несколько реакций или когда уравнение сложное (например, окислительно-восстановительное с непростыми коэффициентами). Число эквивалентов безразмерно и одинаково для всех участников, поэтому ответ получается без подбора коэффициентов. В окислительно-восстановительных реакциях эквивалент считают делением молярной массы на число принятых или отданных электронов.

Как понять, что реагент дан в избытке, если это не сказано прямо?

Разделить количество каждого реагента на его коэффициент в уравнении и сравнить полученные числа: наименьшее отвечает веществу в недостатке. В задаче 3 это 0,01/1 = 0,01 для соли свинца и 0,01/2 = 0,005 для иодида — иодид меньше, по нему и считаем.
